# Governance

This is an independent reference project maintained by Vishnu Govind. The repository does not claim a standards body, financial institution, vendor or public authority as a project sponsor.

## Decision authority

- Architecture choices in the workbench are explicitly selected by the user.
- Findings describe deterministic rules and do not override institutional risk owners.
- Legal ownership, settlement finality and regulatory applicability require authorized legal and compliance review.
- External sources remain attributed to their publishers; initiative announcements do not imply partnership or endorsement.

## Change process

Changes should include rationale, source references for external claims, tests for domain rules, updated limitations and a changelog entry for releases. Breaking workspace schema changes require a version bump and documented migration.

## Versioning

The project uses semantic release tags for published versions. v0.x releases are pre-1.0 and may change schemas or domain behavior with release notes.
