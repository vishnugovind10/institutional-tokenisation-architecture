## What is deployed

The public Vercel site is a browser-based synthetic demonstration. It includes local workspaces, deterministic decision rules, synthetic lifecycle simulations and portable decision outputs. It does not need a login to explore the demo.

The decision engine does not call a live token, custody, bank, payment, transfer-agent or settlement system. Lifecycle state and event history are generated by the local simulator. User supplied data is not independently checked by the app.

## SaaS deployment boundary

The repository contains optional Supabase Auth, tenant-scoped assessment and review code. The public Vercel deployment is not evidence that a Supabase project has been provisioned or connected. SaaS operation requires all of the following to be configured and validated for the target environment:

1. Supabase project and reviewed database migration.
2. Auth confirmation, redirect, recovery and email settings.
3. `save-assessment` and `invite-member` Edge Functions with required secrets.
4. Vercel SaaS environment variables and production redeployment.
5. Tenant isolation, role, audit, backup and restore validation.
6. Independent security review and operational ownership.

Until those steps are completed, describe the public site as a synthetic demo, not a live SaaS service. Do not submit confidential, customer, investor, account or transaction information. The preview has no security review, penetration test, backup restore evidence, service level, billing, enterprise SSO or institutional adoption claim.

## Reproduce locally

```bash
npm ci
npm run dev
```

To regenerate the decision package for the documented synthetic collateral case:

```bash
npm run sample:collateral
```
